## 常用脚本指令
- pnpm login: 登录仓库
- pnpm pub: 全流程(打包->git提交->发布)一键完成
- pnpm push: git提交
- pnpm build: 打包组件库
- pnpm docs-dev: 启动storybook
- pnpm docs-build: 构建storybook
- pnpm up-storybook: 升级storybook相关依赖
- pnpm format: 格式化项目代码
- pnpm lint: 代码检测
- pnpm lint-fix: 代码检测并尝试修复
