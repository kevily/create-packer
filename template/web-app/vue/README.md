## 常用脚本指令
- pnpm dev: 启动项目
- pnpm build: 打包项目
- pnpm build-analyse: 打包分析
- pnpm preview: 预览打包结果
- pnpm push: git提交
- pnpm format: 格式化项目代码
- pnpm lint: 代码检测
- pnpm lint-fix: 代码检测并尝试修复
- pnpm up-vite: 升级vite相关依赖
- pnpm up-tailwind: 升级tailwind相关依赖
- pnpm up-vue: 升级vue相关依赖
